### 📖 About

Welcome to my **SoftUni JS Advanced** repository. This contains all tasks and solutions from the course — a record of going deeper into JavaScript: syntax, arrays, objects, the DOM, advanced functions, unit testing, classes, and prototypes.

### 🛠️ Stack

- **Language:** JavaScript (Node.js)
- **IDE:** VS Code / Cursor
- **Version Control:** Git & GitHub
- **Testing:** Mocha & Chai *(later topics)*
